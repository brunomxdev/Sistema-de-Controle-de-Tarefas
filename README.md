# Sistema de Controle de Tarefas

Projeto de Linguagem de Programação Web 1, feito com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas com nome e descrição opcional
- Validar o campo de nome
- Concluir ou reabrir tarefas
- Excluir tarefas com confirmação
- Mostrar total, pendentes e concluídas
- Salvar tarefas no navegador com localStorage

## Como executar

Abra o arquivo `index.html` no navegador.

## Arquivos

- `index.html`: estrutura da página
- `css/style.css`: aparência
- `js/script.js`: funcionalidades

## Conceitos utilizados

`if/else`, funções, eventos, arrays, `forEach()`, `filter()`, manipulação do DOM e `localStorage`.
